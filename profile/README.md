# Synctune Finance

Synctune Finance is a branch of [Synctune](https://github.com/synctune-io), focused on modern software for business accounting and financial workflows. We help small businesses keep their books, documents, and day-to-day finances in one place.

We partner with [Fire Tools Inc](https://github.com/fire-tools-inc) to bring open source personal finance tools to retail investors.
